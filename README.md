# Programas básicos en C++

Este repositorio contiene algunos de los primeros programas que realicé en mis clases de programación en la universidad.  
Cada uno está escrito en **C++** y tiene como objetivo practicar conceptos fundamentales.

---

## 1. Hola Mundo
Este programa imprime en pantalla el mensaje **"Hola Mundo"**.  
Sirve como introducción al lenguaje y para comprobar que el entorno de desarrollo funciona correctamente.

---

## 2. Cálculo Matemático
El programa solicita un número al usuario y realiza operaciones básicas con él:  
- Suma  
- Resta  
- Multiplicación  
- División  

Es útil para practicar la entrada de datos y las operaciones aritméticas.

---

## 3. Número Par o Impar
Este programa determina si el número ingresado por el usuario es **par** o **impar**.  
Introduce el uso de estructuras condicionales (`if` / `else`) y el operador módulo (`%`).

---

## 4. Área de un Triángulo
El programa pide la **base** y la **altura** de un triángulo y calcula su área con la fórmula:



\[
\text{Área} = \frac{\text{base} \cdot \text{altura}}{2}
\]



Este ejercicio combina entrada de datos, operaciones matemáticas y salida de resultados.

---

## Conclusión
Estos programas representan los primeros pasos en C++:  
- Aprender a mostrar mensajes en pantalla.  
- Realizar cálculos básicos.  
- Usar condiciones para tomar decisiones.  
- Aplicar fórmulas matemáticas simples.  

Son la base para avanzar hacia proyectos más complejos.
